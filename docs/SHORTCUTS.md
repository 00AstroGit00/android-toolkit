# Keyboard Shortcuts

The dashboard provides keyboard-driven navigation. All shortcuts are active globally or context-sensitively per page.

## Global Shortcuts

These shortcuts work from any page:

| Key | Action |
|-----|--------|
| `Q` | Quit the dashboard |
| `Ctrl+C` | Quit the dashboard |
| `F1` | Open help screen |
| `F5` | Refresh all device data |
| `Ctrl+R` | Refresh all device data |
| `Ctrl+L` | Redraw the screen (fix rendering artifacts) |
| `Tab` | Navigate to next sidebar page |
| `Esc` | Go back to previous page (or quit from home) |

## Navigation

| Key | Action |
|-----|--------|
| `↑` / `k` | Navigate up in sidebar or list |
| `↓` / `j` | Navigate down in sidebar or list |
| `→` / `Enter` | Select current item / enter page |
| `←` / `Esc` | Go back to previous page |

## Home Dashboard

On the main dashboard page:

| Key | Action |
|-----|--------|
| `Enter` | Open selected sidebar page |
| `F5` | Refresh dashboard widgets |
| `Esc` | Prompt to quit |
| `Q` | Quit |

## Touch / Mobile

On Android terminals (like Termux), use the volume keys or extended keyboard for navigation. Arrow keys are supported via most mobile keyboard apps (Hacker's Keyboard, Termux:Extra Keys, etc.).
