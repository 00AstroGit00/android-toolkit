# Documentation Browser

Searchable built-in documentation system for the toolkit.

## Categories

| Key | Category |
|-----|----------|
| `1` | User Guide (README) |
| `2` | Dashboard Documentation |
| `3` | CLI Reference |
| `4` | Plugin SDK |
| `5` | Architecture |
| `6` | Troubleshooting |
| `7` | Changelog |
| `8` | Browse All Docs |

## Usage

| Key | Action |
|-----|--------|
| `1-8` | Open documentation category |
| `v` | View current content again |

## Coverage

Displays docs from the `docs/` directory including:
- Phase 1: DASHBOARD.md, THEMES.md, SHORTCUTS.md, TUI_ARCHITECTURE.md
- Phase 3: MULTI_DEVICE.md, AI_ASSISTANT.md, AUTOMATION.md, SECURITY_CENTER.md, SESSION_MANAGER.md, ENTERPRISE_SETTINGS.md, DIAGNOSTICS_CENTER.md
- Core: README.md, CHANGELOG.md, PLUGIN_API.md
