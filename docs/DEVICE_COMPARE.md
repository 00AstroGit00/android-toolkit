# Device Comparison Mode

Compare up to 3 devices side-by-side.

## Comparison Fields

| Field | Description |
|-------|-------------|
| Android Version | Platform version string |
| Security Patch | Last security patch date |
| One UI Version | Samsung One UI build |
| Battery Health | Estimated battery capacity % |
| Thermal | Current device temperature |
| Storage | Used / Total |
| CPU | Processor model |
| Memory | Available / Total RAM |
| Perf Score | Benchmark performance score |
| Security Score | Security assessment score |

## Visual Features

- **Difference Highlighting** — Values differing between devices are highlighted in cyan
- **Status Color** — Green/yellow/red for numeric metrics (battery, storage, thermal)
- **Auto-refresh** — Updates every 5 seconds

## Usage

| Key | Action |
|-----|--------|
| `F5` | Force refresh comparison |
| `F1` | Help |
| `ESC` | Back |
