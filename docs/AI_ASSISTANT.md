# AI Assistant

Rules-based device expert assistant consuming toolkit public APIs.

## Capabilities

- **Health Check** — Device health overview (battery, thermal, storage, memory)
- **Quick Optimize** — Balanced optimization with rollback safety
- **Battery Analysis** — Status, optimization tips, health metrics
- **Security Scan** — Audit current posture and receive recommendations
- **Storage Management** — Cache trim, package cleanup guidance
- **Memory Analysis** — Usage stats, swap info, OOM configuration
- **Benchmark** — Quick performance benchmarking
- **CLI Help** — Command reference and examples
- **Version Info** — Toolkit and device version details

## Quick-Action Keys

| Key | Action |
|-----|--------|
| `h` | Health check |
| `o` | Quick optimize |
| `b` | Battery analysis |
| `s` | Security scan |
| `t` | Storage management |
| `m` | Memory analysis |
| `n` | Benchmark |
| `?` | List all commands |
| `q` | Back |

## Architecture

No external LLM required. All responses are generated by querying:
- `status_get()` — device metrics
- `backend_exec()` — shell commands
- `audit_run()` — security audit
- `benchmark_run()` — performance testing
- `performance_apply_profile()` — optimization
